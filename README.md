# Autoresearch

Кросс-платформенный скилл для AI-агентов (Antigravity, Codex, Claude Code и других) для исследования данных из CSV, таблиц и SQL-запросов, а также глубокого исследования тем с проверкой источников.

## Установка

Скопируйте содержимое репозитория в каталог скиллов вашего агента:

- **Antigravity (глобально):** `~/.gemini/config/skills/autoresearch`
- **Codex:** `skills/autoresearch`
- **Проектный скилл (универсально):** `.agents/skills/autoresearch`

## Состав

- `SKILL.md` — основной сценарий исследования.
- `references/` — инструкции по данным, методике, проверке и ведению прогона.
- `scripts/` — сервер дашборда и валидатор состояния.
- `assets/` — шаблон дашборда.
- `tests/` — контрольные примеры и проверки.
- `LICENSE` — лицензия MIT.
