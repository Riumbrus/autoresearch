# Autoresearch

Скилл Codex для исследования данных из CSV, таблиц и SQL-запросов, а также глубокого исследования тем с проверкой источников.

## Установка

Скопируйте содержимое каталога скилла в каталог навыков Codex `skills/autoresearch`.

## Состав

- `SKILL.md` — основной сценарий исследования.
- `references/` — инструкции по данным, методике, проверке и ведению прогона.
- `scripts/` — сервер дашборда.
- `assets/` — шаблон дашборда.
- `tests/` — контрольные примеры и проверки.
